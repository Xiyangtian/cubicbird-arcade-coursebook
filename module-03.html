功能 03

敌人巡逻

让敌人自己在地图里走来走去，撞墙还会掉头

🎯 本节目标
  • 创建敌人精灵并设置种类为 Enemy
  • 给敌人设置速度，让它自己巡逻
  • 让敌人碰到墙壁后反弹
  • 读出敌人当前的速度
  • 让敌人根据移动方向改变朝向
  • 添加多个不同速度的敌人
✏️ 课前准备

两种方式二选一：

  • 方式一（推荐）：如果上一个功能的项目完成了，直接打开自己的项目（功能02-地图与墙壁碰撞）
  • 方式二：如果上一个功能没完成，找老师要项目链接，打开后点击 "编辑" 或 "复制" 到自己账号里
步骤 1创建敌人精灵

在场景中创建一个敌人精灵。

  1. 在左侧积木区找到 精灵 指令集
  2. 拖动积木 精灵 → 创建 → 将 [变量名] 设为精灵 [图像] 类型 [类型] 到代码区
  3. 点击精灵图像，进入精灵图像编辑器，绘制敌人图像
  4. 给敌人起一个变量名，例如 小怪1
  5. 把精灵种类设为 Enemy
  6. 用 场景 → Tilemap Operations → 放置 [小怪1] 在图块地图 [列] [行] 上面，把敌人放到地图的某个位置

💡 敌人不要放在墙里面，也不要和玩家角色重叠。

步骤 2设置运动速度

给敌人设置速度，让它自己动起来。怎么动？由你自己决定！

  1. 找到 精灵 → 物理 → 将 [小怪1] 的速度设置为 vx 50 vy 50，拖动到代码区
  2. 运行游戏，按下表把 vx、vy 改成不同的数字测试，看看敌人分别怎么动，把结果记下来：
测试vxvy敌人怎么动？
第 1 次500
第 2 次-500
第 3 次050
第 4 次0-50
第 5 次1000
  1. 想好你想要的巡逻方式，设置对应的速度
图 3-1：设置运动速度积木

💡 vx 是水平速度，正数向右、负数向左；vy 是垂直速度，正数向下、负数向上；设成 0 就是那个方向不动。

步骤 3敌人碰墙反弹

敌人走到墙壁时，自动掉头往回走。

  1. 在 精灵 指令集里找到 特效 分类
  2. 拖动积木 精灵 → 特效 → set [小怪1] bounce on wall 开（这个指令还是英文的，意思是"碰到墙壁就反弹"）
  3. 运行游戏，观察敌人撞墙后是不是自动掉头了
图 3-2：敌人碰墙反弹积木

💡 bounce on wall 翻译过来就是"碰到墙壁反弹"。打开这个开关后，敌人撞到墙壁会自动掉头，不用自己写判断，并且只需要设置一次。

步骤 4让敌人说出当前速度

让敌人把当前的速度说出来，看看 vx 是怎么变化的。

  1. 拖动 游戏 → 游戏内容 → 当游戏更新时 事件到代码区
  2. 在事件里放入 精灵 → 特效 → [小怪1] say [ :) ]，把内容改成 精灵 → 物理 → [小怪1] 的 [vx]
  3. 运行游戏，看敌人头上的数字：向右走时是多少？撞墙反弹后变成多少？
图 3-3：当游戏更新时积木
图 3-4：精灵说积木
图 3-5：精灵的 vx 积木

💡 [小怪1] 的 [vx] 可以随时读出敌人当前的速度。撞墙反弹后 vx 会变成负数，数字也跟着变号。

步骤 5敌人精灵的左右朝向

敌人向右走时面向右，向左走时面向左。

  1. 打开精灵图像编辑器，用翻转图像功能，把敌人的图像做成一张朝左的，保存成另一张图像
  2. 回到 当更新时 的循环里，把上一步的 精灵 say 积木换成 逻辑 → 条件 → 如果 [小怪1] 的 [vx] > 0 那么 ... 否则 ...
  3. vx 大于 0（向右走）：用 精灵 → 图像 → 设置 [小怪1] 的图像为 [朝右的图]
  4. vx 小于 0（向左走）：用 设置 [小怪1] 的图像为 [朝左的图]
  5. 运行游戏，观察敌人掉头时图像是不是也跟着换了
图 3-6：如果……那么……积木
图 3-7：vx 大于 0 比较积木
图 3-8：设置图像积木

💡 敌人撞墙反弹后 vx 会变成负数，所以向左走时要用朝左的图像。

步骤 6添加第二个敌人

再添加一个速度不同的敌人，让场景更丰富。

  1. 再创建一个敌人，变量名 小怪2
  2. 把 小怪2 放到地图的另一个位置
  3. 设置一个和 小怪1 不同的方向和不同的速度
  4. 记得设置 小怪2 碰到墙壁反弹
  5. 让 小怪2 也会根据移动方向改变朝向
  6. 运行游戏，观察两个敌人是不是都在巡逻
步骤 7测试与调整

运行游戏，检查整体效果，调整不满意的地方。

检查清单
  • 敌人能自动巡逻
  • 敌人撞墙会反弹
  • 敌人掉头时朝向会改变
  • 两个敌人的速度和方向不一样
  • 敌人没有出生在墙里面
图 3-9：运行效果参考
可调整的参数
参数作用建议
速度 vx/vy控制敌人巡逻的方向和快慢想横着巡逻就把 vy 设为 0
敌人位置（列、行）控制敌人出生在哪一格图块别放在墙里面
敌人数量控制场景里有多少个敌人2-3 个就够热闹了
⚠️ 易错点与提示
  • 敌人不动：
    • 检查 vx 和 vy 是不是都被设成了 0
  • 敌人不反弹：
    • 检查 bounce on wall 是不是设成了"开"
  • 敌人朝向不对：
    • 检查两张图像是不是搞反了
    • 检查判断条件：向右走（vx > 0）用朝右的图，向左走（vx < 0）用朝左的图
