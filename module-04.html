功能 04

受伤、生命与游戏结束

给玩家加上生命值，受伤扣血，生命归零游戏结束

🎯 本节目标
  • 设置并显示生命值
  • 玩家碰到敌人后扣减生命值
  • 生命值为 0 时结束游戏
  • 用镜头抖动增强受伤反馈，用暂停避免连续扣血
✏️ 课前准备

两种方式二选一：

  • 方式一（推荐）：如果上一个功能的项目完成了，直接打开自己的项目（功能03-敌人巡逻）
  • 方式二：如果上一个功能没完成，找老师要项目链接，打开后点击 "编辑" 或 "复制" 到自己账号里
步骤 1设置生命值

给玩家设置初始生命值，并在屏幕上显示出来。

  1. 在左侧积木区找到 游戏信息 指令集
  2. 拖动积木 游戏信息 → 生命值 → 将生命设置为 [3] 到 当开机时
  3. 运行游戏，观察屏幕右上角是否出现心形图标和数字
图 4-1：设置生命值积木

💡 将生命设置为 是游戏自带的生命系统，设置后屏幕右上角会自动显示心形和数字，不用自己画。

步骤 2碰到敌人扣血

当玩家和敌人重叠时，玩家生命减少。

  1. 在左侧积木区找到 精灵 指令集
  2. 拖动积木 精灵 → 重叠 → 当 [Player] 与 [Enemy] 重叠时 到代码区
  3. 在事件里放入 游戏信息 → 生命值 → 改变生命 [-1]
  4. 运行游戏，控制玩家撞向敌人，观察生命是否减少

图 4-3：改变生命积木

🤔 想一想：撞上敌人后，生命会不会连续往下掉？为什么会这样？我们到步骤 5 再解决这个问题。

步骤 3生命为 0 时游戏结束

当生命值降到 0 时，显示游戏结束画面。

  1. 在左侧积木区找到 游戏信息 指令集
  2. 拖动积木 游戏信息 → 生命值 → 当生命值为 0 时 事件到代码区
  3. 在事件里放入 游戏 → game over [失败]（这个指令还是英文的，意思是"游戏结束"）
  4. 运行游戏，故意把生命耗光，观察游戏结束画面
图 4-4：当生命值为零时积木
图 4-5：游戏结束积木

💡 当生命值为 0 时 会在生命降到 0 时自动触发，不用自己写判断。game over（游戏结束）会停止游戏并显示胜利或失败画面。

步骤 4受伤时屏幕抖动

受伤时让屏幕抖动一下，让玩家明显感觉到"被打了"。

  1. 在 当 [Player] 与 [Enemy] 重叠时 事件里，扣血之后放入 场景 → 镜头 → 镜头抖动 [4] 像素持续 [500] 毫秒
  2. 运行游戏，撞向敌人，观察屏幕是不是抖了一下
图 4-6：受伤屏幕抖动积木
步骤 5受伤后暂停一下

扣血后暂停一小会儿，让生命不要连续往下掉。

  1. 在 当 [Player] 与 [Enemy] 重叠时 事件里，扣血之后放入 循环 → 暂停 [800] 毫秒
  2. 运行游戏，撞向敌人后松开方向键停在原地，观察生命是不是不会"哗哗"往下掉了（而是 800 毫秒才扣一次）
图 4-7：暂停防连续扣血积木

💡 暂停 会停住当前这一小段代码，等时间到了再继续。800 毫秒是老师测试过的值，觉得太久或太短，可以自己改数字再试试。

步骤 6测试与调整

反复测试，确保生命系统正常工作。

检查清单
  • 游戏开始时生命显示为 3
  • 碰到敌人后生命减少 1
  • 生命减到 0 时游戏结束
  • 受伤时屏幕会抖动
  • 撞上敌人后生命不会连续往下掉

可调整的参数
参数作用建议
初始生命玩家能承受的攻击次数初学者建议 3

⚠️ 易错点与提示
  • 碰到敌人生命一直掉：
    • 重叠事件每帧都会触发，暂停要放在扣血之后，否则起不到间隔作用
  • 生命到 0 但游戏不结束：
    • 检查是否使用了 当生命值为 0 时 事件
    • 检查 game over 是否放进了这个事件里
  • 生命没有显示：
    • 检查是否使用了 游戏信息 → 生命值 → 将生命设置为 积木
