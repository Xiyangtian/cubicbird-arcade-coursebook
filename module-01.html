功能 01

俯视角角色移动

创建你的第一个角色，用方向键控制它自由行走

🎯 本节目标
  • 在 MakeCode Arcade 中创建一个新项目
  • 创建并编辑一个精灵（Sprite）
  • 设置精灵的初始位置
  • 使用控制器让精灵上下左右移动
  • 设置场景背景颜色
✏️ 课前准备
  • 打开浏览器，进入 MakeCode Arcade 编辑器
  • 点击 「新建项目」，给项目起个名字，例如：功能01-角色移动
步骤 1创建玩家精灵

在场景中创建一个玩家角色。

  1. 在左侧积木区找到 精灵 指令集
  2. 拖动积木 精灵 → 创建 → 将 [变量名] 设为精灵 [图像] 类型 [类型] 到代码区
  3. 给这个精灵起一个变量名，例如 蜗牛
  4. 点击精灵图像，进入精灵图像编辑器
  5. 可以选择 编辑器、图库、我的资产，分别可以自己画一个图像、选择图库里的图像、选择作品中有的图像
  6. 将精灵种类设为 Player（玩家），也可以自己添加新的类型
图 1-1：创建玩家精灵积木

💡 也可以选择图库里的图像后，再进行个性化修改。

步骤 2设置精灵位置（x/y 坐标）

用 x/y 坐标让角色出现在屏幕左上角附近。

  1. 在左侧积木区找到 精灵 指令集
  2. 拖动积木 精灵 → 物理 → 设置 [mySprite] 的位置为 x y 到代码区
  3. 把它放到 创建精灵 积木下面
  4. 把 mySprite 改成你自己创建的精灵变量名，例如 蜗牛
  5. 将 x 设为 20，y 设为 20
图 1-2：设置精灵位置积木

💡 这里设置的是精灵的 x/y 像素坐标，屏幕左上角是 (0, 0)，右下角是 (160, 120)。如果没有创建这个精灵就设置它的位置，会报错哦～

步骤 3控制器移动

按键盘方向键，角色可以上下左右移动。

  1. 在左侧积木区找到 控制器 指令集
  2. 拖动积木 控制器 → 单人游戏 → 使用按键移动 [mySprite] 到代码区
  3. 把它放到 设置位置 积木下面
  4. 把 mySprite 改成你自己创建的精灵变量名，例如 蜗牛
  5. 点击积木上的 +，展开后会多出 vx 和 vy 两个参数
  6. vx 和 vy 默认就是 100，可以试试改大一点或改小一点，看看角色移动速度的变化
图 1-3：控制器移动积木

💡 v 是速度（velocity）的缩写。vx 表示水平方向（左右）的速度，vy 表示垂直方向（上下）的速度。数值越大，角色移动越快。

🧪 点击右侧模拟器，试试用键盘方向键控制精灵移动。

📢 如果按了没反应，看看模拟器按钮是不是灰色的——灰色说明键盘没有聚焦到模拟器上，点击一下模拟器画面再试。

步骤 4设置背景颜色

给游戏加一个好看的背景颜色。

  1. 在左侧积木区找到 场景 指令集
  2. 拖动积木 场景 → 设置背景颜色为
  3. 选择一个你喜欢的颜色
图 1-4：设置背景颜色积木

💡 如果觉得纯色背景太单调，可以看看背景颜色指令下面的 设置背景图片 指令，选择或绘制一张背景图片。

步骤 5测试与调整

运行游戏，检查效果，调整不满意的地方。

检查清单
  • 角色出现在屏幕左上角
  • 按键能移动
  • 速度合适
  • 背景不是纯黑色
可调整的参数
参数作用建议
移动速度 vx/vy控制左右/上下移动速度数值越大移动越快，建议 80-150
初始位置 x/y控制角色出现的位置建议在屏幕范围内

  2. 等待生成分享链接
  3. 复制链接，发给老师或同学

⚠️ 易错点与提示
  • 角色没有显示：
    • 检查 创建精灵 积木是不是放在 当开机时 积木里面
    • 检查 设置位置 的 x/y 是不是太大了，角色跑到屏幕外去了（屏幕最大是 160×120）
  • 按方向键角色不动：
    • 检查键盘是不是没有聚焦到模拟器上（模拟器按钮是灰色的话，先点击模拟器画面再试）
    • 检查 使用按键移动 积木是否连在了 创建精灵 积木下面
    • 检查 使用按键移动 里的精灵变量名，和 创建精灵 里的变量名是否一致（比如都是 蜗牛）
  • 角色移动太快/太慢：
    • 调整 使用按键移动 积木里的 vx/vy 数值，数值越大移动越快
  • 角色图像不满意：
    • 点击精灵图像，进入精灵图像编辑器重新修改，或换个图库图像
🚀 扩展挑战

完成基础任务后，可以尝试：

  • 改变角色朝向：当按左键时角色面向左，按右键时面向右
    • 提示 1：在精灵图像编辑界面，可以用翻转图像功能，快速把面向右的图像改成面向左的图像
    • 提示 2：用 设置 [mySprite] 的图像为 [xx] 指令，配合 当按键 [左/右] 按下 事件，按不同方向键时切换成对应的图像
  • 限制角色不能跑出屏幕：
    • 使用 set [mySprite] stay in screen 开 指令（这个指令还是英文的，平台中文化没有完全做好）
  • 添加第二个精灵：再创建一个精灵，用 设置位置 把它放到屏幕右下角
  • 自由探索：到积木区逛逛，把没见过的指令集（比如 音乐、游戏信息、动画）里的指令拖到代码区试试，运行看看会发生什么
