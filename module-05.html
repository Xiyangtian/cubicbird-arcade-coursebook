功能 05

射击与分数

按 A 键发射子弹消灭敌人，得分到达目标就获胜

🎯 本节目标
  • 设置并显示分数
  • 按 A 键发射子弹（弹射物）
  • 子弹击中敌人后销毁并加分
  • 分数达到目标时游戏获胜
✏️ 课前准备

两种方式二选一：

  • 方式一（推荐）：如果上一个功能的项目完成了，直接打开自己的项目（功能04-受伤生命与游戏结束）
  • 方式二：如果上一个功能没完成，找老师要项目链接，打开后点击 "编辑" 或 "复制" 到自己账号里
步骤 1设置分数

在屏幕上方显示分数，从 0 开始。

  1. 在左侧积木区找到 游戏信息 指令集
  2. 拖动积木 游戏信息 → 得分 → 将得分设置为 [0] 到 当开机时
  3. 运行游戏，观察屏幕上方是否出现分数
图 5-1：设置分数积木

💡 分数和生命一样是游戏自带的，设置后会自动显示在屏幕上方，不用自己画。

步骤 2按键发射子弹

按 A 键时，从玩家身上发射一颗子弹。

  1. 在左侧积木区找到 控制器 指令集
  2. 拖动积木 控制器 → 当按钮 A 按下时 到代码区
  3. 在里面放入 精灵 → 弹射物 → 将 [projectile] 设为弹射物从 [mySprite] 以 vx [50] vy [50]
  4. 点击图像，画一颗子弹
  5. 运行游戏，按 A 键，观察子弹是不是从玩家身上飞出去
图 5-2：发射子弹积木

💡 Projectile 是英文，中文叫弹射物（也叫抛射物），就是子弹这种从精灵身上发射出去、会自动往前飞的东西。它本质上也是一个精灵，所以图像、重叠、销毁这些积木对它都适用。积木里的 vx、vy 决定子弹飞行的方向和快慢——正负号决定方向、数字大小决定速度，可以自己改数字试试。

步骤 3子弹击中敌人后销毁并加分

子弹碰到敌人时，敌人消失，分数加 1。

  1. 在左侧积木区找到 精灵 指令集
  2. 拖动积木 精灵 → 当 [Projectile] 与 [Enemy] 重叠时 到代码区
  3. 在事件里放入 精灵 → 特效 → destroy（这个指令还是英文的，意思是"销毁"），再把事件自带的 otherSprite（局部变量，代表被碰到的那个精灵）拖到 destroy 里
  4. 再放入 游戏信息 → 得分 → 改变得分 [1]
  5. 运行游戏，射击敌人，观察敌人消失、得分增加
图 5-3：重叠事件积木
图 5-4：销毁与加分积木

💡 要不要把子弹也一起销毁？由你自己决定——销毁子弹，一颗子弹只能打一个敌人；不销毁，子弹会继续飞，可能打中更多敌人。

步骤 4得分达到目标后游戏获胜

分数达到目标时，显示胜利画面。

  1. 在左侧积木区找到 游戏信息 指令集
  2. 拖动积木 游戏信息 → 得分 → on score [N] 事件到代码区（这个指令还是英文的，意思是"当得分为"）
  3. 在事件里放入 游戏 → game over [胜利]（这个指令还是英文的，意思是"游戏结束"）
  4. 想一想：N 填多少？地图上有几个敌人，消灭一个加 1 分，全部消灭就胜利，所以 N 填敌人的数量
  5. 运行游戏，消灭所有敌人，观察胜利画面
图 5-5：得分获胜积木

💡 on score 会在分数达到指定数字时自动触发，和功能04 的 当生命值为 0 时 很像，不用自己写判断。

步骤 5测试与调整

完整测试射击、得分和获胜系统。

检查清单
  • 按 A 键能发射子弹
  • 子弹会自己向前飞
  • 子弹击中敌人后，敌人消失、分数增加 1
  • 分数到达目标后显示胜利画面
  • 玩家碰到敌人仍然扣血
  • 生命为 0 时游戏结束

可调整的参数
参数作用建议
子弹速度 vx/vy子弹飞行的方向和快慢自己试，50-200 比较合适

⚠️ 易错点与提示
  • 按 A 键没有子弹：
    • 检查是否使用了 当按钮 A 按下时 事件
    • 检查弹射物积木是否设置好了 vx、vy
  • 子弹不飞向敌人：
    • 检查 vx、vy 的正负号，往哪边飞取决于它们的值
  • 子弹穿过敌人：
    • 检查重叠事件的种类是否正确（Projectile 与 Enemy）
    • 检查是否调用了 destroy
  • 分数不增加：
    • 检查 改变得分 是否放在了重叠事件里
    • 检查事件是否触发（子弹有没有碰到敌人）
  • 分数到了但游戏不获胜：
    • 检查 on score 里的数字是否等于敌人数量
    • 检查 game over 是否放进了这个事件里
