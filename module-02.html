功能 02

地图与墙壁碰撞

画一张自己的地图，让墙壁真的能把角色挡住

🎯 本节目标
  • 使用地图编辑器（Tilemap）绘制场景
  • 给地图中的某些图块设置为"墙壁"
  • 让角色在场景中不能穿墙
  • 让相机跟随角色移动
✏️ 课前准备

两种方式二选一：

  • 方式一（推荐）：如果上一个功能的项目完成了，直接打开自己的项目（功能01-角色移动）
  • 方式二：如果上一个功能没完成，找老师要项目链接，打开后点击 "编辑" 或 "复制" 到自己账号里
步骤 1绘制地图

用地图编辑器设计一张比屏幕大的迷宫或房间，先用墙壁图块把"墙"画出来。

  1. 在左侧积木区找到 场景 指令集
  2. 拖动积木 场景 → Tilemaps → 设置图块地图为 [tilemap] 到代码区
  3. 点击积木中的灰色方框，打开地图编辑器
  4. 先认识一下编辑器（和画精灵图像很类似）：界面上有编辑器 / 图库 / 我的资产几个区域；左下角可以修改地图大小，默认就是 16 × 16 个图块，够用了，不用改
  5. 在编辑器左下角选择图块，开始绘制地图：先选"墙壁"图块，画一圈墙壁（这决定了地图的外形）；再换其他图块（比如地面），画出角色可以行走的通道；可以先画一个简单的矩形房间，再慢慢改成迷宫
  6. 点击编辑器右下角的"完成"按钮，返回代码区，然后运行游戏测试

图 2-2：地图编辑器参考

🤔 想一想：现在角色是不是可以直接穿过墙壁？因为这时墙只是"画出来"的样子，还没变成真正的墙。下一步我们就把它变成真墙。

步骤 2把墙壁变成真正的墙

把刚才画出来的墙壁图块设为"墙"，让角色碰到后不能穿过去。

  1. 点击 设置图块地图 积木上的灰色方框，重新打开地图编辑器
  2. 在编辑器左侧点击"墙"设置按钮（把画笔切换成"画墙"模式）
  3. 用画笔在地图中所有墙壁图块上重新绘制一遍
  4. 点击编辑器右下角的"完成"按钮，返回代码区，然后点击模拟器测试
  5. 控制角色撞向墙壁，看是否被挡住
图 2-3：设置墙壁碰撞

💡 小知识：墙设置是在地图编辑器里完成的，不需要拖积木；被设为墙的图块会自动产生碰撞；使用"平铺"按钮，在地图上点一下，就能快速把连在一起的墙壁图块一次性全部设为墙。

步骤 3把角色放到地图中测试

用"列、行"把角色放到地图入口，确保它出生在合适的图块上。

  1. 找到 场景 指令集中的 场景 → Tilemap Operations → 放置 [mySprite] 在图块地图 [列] [行] 上面，拖动到代码区
  2. 把它放到 当开机时 里创建精灵、设置图块地图之后
  3. 打开地图编辑器，把鼠标移到想让角色出生的图块上
  4. 在左下角（地图大小旁边）读出位置数字，例如 2, 3（前一个是列，后一个是行）
  5. 把数字填进积木：列填 2、行填 3
  6. 运行游戏，检查角色是否出现在正确的位置
图 2-4：放置角色到地图

⚠️ 注意：这里用的是列、行（第几格图块），和功能 01 里 设置位置 的 x、y（像素坐标）不一样。有地图以后用列、行放角色更方便准确。填数字时前一个是列，后一个是行。

大小对比： 一个图块是 16 × 16 像素 默认地图是 16 × 16 个图块，也就是 256 × 256 像素 游戏屏幕只有 160 × 120 像素，所以地图比屏幕大，角色可以走出屏幕范围 用下面这个 4 × 2 的地图来理解（每格是一个图块）： 列 0 列 1 列 2 列 3 ┌──────┬──────┬──────┬──────┐ │ │ │ │ │ 行 0 ├──────┼──────┼──────┼──────┤ │ │ │ │ │ 行 1 └──────┴──────┴──────┴──────┘ 数字 0, 0 就是最左上角那一格：前一个数（列）往右数，后一个数（行）往下数。
步骤 4添加相机跟随

让镜头一直跟随玩家角色，防止角色走出屏幕后看不到。

  1. 在左侧积木区找到 场景 指令集
  2. 拖动积木 场景 → 镜头 → 镜头跟随精灵 [mySprite] 移动 到代码区
  3. 把它放到 当开机时 里创建精灵之后
  4. 把 mySprite 改成你自己创建的精灵变量名
图 2-5：添加相机跟随

💡 如果没有相机跟随，角色走出屏幕后就看不到了。

步骤 5测试与调整

美化地图，并检查整体效果。

检查清单
  • 地图比屏幕大，角色可以四处走动
  • 相机跟随角色移动
  • 墙壁能挡住角色
  • 角色没有出生在墙里面
  • 地图看起来美观、路径清晰
图 2-6：运行效果参考
可调整的参数
参数作用建议
地图大小控制地图有多宽多高默认 16×16 即可，够大了
墙图块决定哪些图块不能穿过路径图块不要设为墙
⚠️ 易错点与提示
  • 角色能穿过墙壁：
    • 检查是否用墙设置按钮把墙壁图块设为了墙
  • 相机不跟随角色：
    • 检查 镜头跟随精灵 积木中的精灵变量名是否正确（比如都是 蜗牛）
    • 检查是否先创建精灵，再相机跟随精灵
  • 角色出生在墙里：
    • 调整 放置 [mySprite] 在图块地图 [列] [行] 上面 的列、行值，让角色出生在空地上
🚀 扩展挑战

完成基础任务后，可以尝试：

  • 在地图位置放置一个其他精灵：
    • 再创建一个精灵（比如一只怪兽或一个宝箱），用 放置 [mySprite] 在图块地图 [列] [行] 上面 把它放到地图的某个位置
    • 运行游戏，走去找找它在哪里
  • 扩大地图并划分区域：
    • 把地图扩大到 20 × 40 左右
    • 用不同图块划分出草地、岩石、水域等区域
    • 把水域或岩石的边缘设为墙，形成"不能走"的区域边界
  • 自由探索：到积木区逛逛，把没见过的积木拖到代码区试试，运行看看会发生什么
